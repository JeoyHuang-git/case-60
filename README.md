# CASE//60：百案迷局（100 关深度推理版）

## 主要功能
- 100 关固定顺序闯关（前 20 起承接旧版本案件，新增 80 起不同场景案件），每 10 关进入新的难度阶段。
- 第 1–40 关：2 条关键证据；41–80 关：3 条；81–100 关：4 条。
- 每关限时 60 秒；错误指认扣除 50 分，随难度阶段加重扣时；提示扣分。
- 可暂停、从游戏或结算返回主页、下次继续进度，或确认后从第 1 关重新开始。
- 自动存档：关卡、分数、剩余时间、选中的证据、嫌疑人、结算状态等；历史最高分独立保存。
- 电脑键盘 / 鼠标与手机触控均可玩，无外部 CDN，完全静态部署。

## VS Code 本地运行
1. 解压 ZIP。
2. VS Code 打开本文件夹。
3. 右键 `index.html` → `Open with Live Server`，或者双击 `index.html` 用浏览器打开。
4. 点击「开始新调查」。

## 操作
- 1–8：选择对应证据
- Q/W/E/R/T：选择对应嫌疑人
- Enter：提交推理
- P / Esc：暂停或继续
- 触屏端：直接点击证据、人物和界面按钮

## 存档规则
存档由浏览器 localStorage 保存，按同一网站域名区分；不是云存档。换手机/浏览器或清理网站数据会丢失关卡进度。重新开始会清除当前进度，但保留此版本最高分。切出标签页或锁屏时游戏自动暂停。

## 更新 GitHub Pages
将 `index.html`、`style.css`、`game.js`、`cases.js`、`README.md` 上传到你现有 GitHub 仓库 `case-60` 的根目录，与原文件同名则覆盖，注意上传新增的 `cases.js`。进入 `Settings > Pages`，确保配置为 `main` + `/(root)`。发布完成后仍用原网址 `https://jeoyhuang-git.github.io/case-60/`，无需新建仓库。

## 案件说明
前 20 关延续原版的双证据玩法。第 21–100 关各有不同地点、案件标题、资产与涉案人物；中高难度要求额外的流转证明和防篡改复核。后 80 关的证据链采用统一可验证的推理机制模板，因此它们是 80 个独立关卡与不同背景故事，但不是 80 套完全不同的逻辑谜型。若计划商业化，可进一步逐案精修、增加多结局与交叉证词逻辑。

## 文件
- `index.html` 页面与弹窗
- `style.css` 响应式视觉与动画
- `cases.js` 100 起案件数据（可直接编辑案件）
- `game.js` 游戏逻辑、计分、存档、暂停与音效
- `README.md` 本说明
