# CASE//60 · 60 秒破案挑战

一款原创的手机 / 平板 / 电脑通用、无需后端的侦探推理网页小游戏。**整个游戏逻辑可以离线运行**（页面的 Google 字体无法联网时会自动使用系统字体）。

## 玩法

- 每轮随机抽出 6 起案件，每案限时 60 秒。
- 阅读现场报告，选出一条能直接推翻证词的**关键物证**。
- 阅读三个嫌疑人的口供，再选择对应的嫌疑人。
- 证据与嫌疑人都选对才算破案；选错扣 60 分以及 10 秒；时间结束会揭晓答案。
- 破案获得基础分 + 剩余秒数奖励 + 连胜加成；六案结束后显示总分和历史最高分。
- **注意：这是逻辑推理小游戏。线索主要锁定口供矛盾，并不代表现实刑事案件中足以定罪的证据。**

## 操作

- **电脑：**鼠标点击；Q/W/E 选择三条物证，1/2/3 选择嫌疑人，Enter 提交，M 切换音效。
- **手机和平板：**触屏点选证物、嫌疑人，点击「提交最终指认」。
- 音效由浏览器 Web Audio API 实时合成，首次点击游戏按钮后才可播放；不需要音频素材或额外下载。
- 关闭或切换浏览器标签页时，正在进行的倒计时会自动暂停，返回后继续。

## 文件

- `index.html` — 所有界面的结构
- `style.css` — 响应式视觉设计和动画
- `game.js` — 12 起原创案件、计时、判题、音效、记分、存档

## VS Code 运行

1. 使用 VS Code 打开本文件夹。
2. 安装扩展 Live Server（Ritwick Dey）。
3. 右键点击 `index.html` → `Open with Live Server`。
4. 也可以在文件管理器中直接双击 `index.html` 打开（游戏无外部 JS 依赖）。

## 免费发布到 GitHub Pages

1. 登录 GitHub，创建公开仓库，例如 `case-60`。
2. 进入仓库 `Add file → Upload files`，**上传 `index.html`、`style.css`、`game.js`、`README.md` 这四个文件本身，不要上传 ZIP 或包裹文件夹**。
3. 确保仓库首页（根目录）直接能看到 `index.html`。
4. `Settings → Pages → Build and deployment`：Source 选择 `Deploy from a branch`，Branch 选 `main`，Folder 选 `/(root)`，保存。
5. 构建成功（`Actions` 中绿色对勾）后访问 `https://你的GitHub用户名.github.io/case-60/`。
6. 将最终实际访问成功的网址发送给朋友。GitHub Pages 是静态托管，朋友不需要 GitHub 账号。

## 关于最高分和多人

最高分使用当前浏览器 `localStorage` 保存。**不同设备最高分不会同步，也没有在线排行榜**。分享成绩使用系统分享功能或复制文本。
